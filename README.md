## Опис проєкту
Покрокова консольна реалізація класичної гри «Морський бій» мовою **Python 3** без зовнішніх залежностей.

### Ключові особливості та структури даних:
- **Динамічні двовимірні матриці (`list[list[str]]`)**: незалежні матриці поля гравця (`player_board`), внутрішнього поля бота (`bot_board`) та проекції «туману війни» (`player_view`).
- **Валідація розміщення флоту**: перевірка меж матриці $10 \times 10$ та буферної зони $3 \times 3$ навколо кожної палуби.
- **Пошук у ширину (BFS)**: визначення всіх палуб ураженого корабля на 4-зв'язній решітці (`get_ship_coordinates`) та автоматичне заповнення ореолу потопленого корабля символами `*`.
- **Процедурний ШІ бота (`HUNT` / `TARGET`)**: скінченний автомат із шаховою евристикою парності координат `(r + c) % 2 == 0` у фазі розвідки та визначенням осі корабля у фазі добивання.
